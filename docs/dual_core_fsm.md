# Asymmetric Dual-Core Architecture & FreeRTOS Scheduling                                                                                                                                                                                       
                                                                                                                                                                                                                                                    
  This document details the multi-core task segregation, priority assignment, and inter-processor communication (IPC) implemented on the **ESP32-S3 Dual-Core Xtensa LX7 @ 240 MHz**.                                                             
                                                                                                                                                                                                                                                  
  ---                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                  
  ## 1. Core Allocation & Task Segregation                                                                                                                                                                                                        
                                                                                                                                                                                                                                                  
  To guarantee deterministic timing, tasks are pinned to specific cores to isolate real-time rendering from network latency:                                                                                                                      
                                                                                                                                                                                                                                                  
  | Task Name | Core Affinity | Priority | Stack Size | Execution Budget | Role |                                                                                                                                                                 
  | :--- | :---: | :---: | :---: | :---: | :--- |                                                                                                                                                                                                 
  | `led_render_task` | **Core 1** | `configMAX_PRIORITIES - 1` | 4096 B | 6.94 ms (144 Hz) | Hardware frame generation, DSP smoothing & RMT driving |                                                                                            
  | `udp_audio_task` | **Core 0** | `configMAX_PRIORITIES - 3` | 4096 B | Asynchronous (50 Hz) | Non-blocking UDP packet receipt & validation |                                                                                                   
  | `http_server_task`| **Core 0** | `tskIDLE_PRIORITY + 3` | 8192 B | Event-driven | REST API parsing and client response |                                                                                                                      
  | `wifi_fsm_task` | **Core 0** | `tskIDLE_PRIORITY + 2` | 3072 B | Event-driven | Wi-Fi reconnect state machine & mDNS discovery |                                                                                                              
  | `nvs_debounce_task`| **Core 0** | `tskIDLE_PRIORITY + 1` | 2048 B | 1000 ms debounce | Persistent storage write-back protection |                                                                                                             
                                                                                                                                                                                                                                                  
  ---                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                  
  ## 2. Lockless State Synchronization (IPC)                                                                                                                                                                                                      
                                                                                                                                                                                                                                                  
  Mixing critical timing loops with standard mutexes introduces priority inversion and indeterministic context switches.                                                                                                                          
                                                                                                                                                                                                                                                  
  ### Zero-Allocation Atomic Double-Buffering                                                                                                                                                                                                     
  - **Shared State Buffer:** The application maintains a double-buffered lighting state struct.                                                                                                                                                   
  - **Atomic Pointer Swap:** When Core 0 validates a new payload (from UDP or REST), it populates the back buffer and performs an atomic pointer swap.                                                                                            
  - **Deterministic Read on Core 1:** Core 1 reads from the active buffer without acquiring locks or blocking execution.                                                                                                                          
                                                                                                                                                                                                                                                  
  ```text                                                                                                                                                                                                                                         
  [Core 0: Network Ingestion]                                                                                                                                                                                                                     
          │                                                                                                                                                                                                                                       
          ▼ (Write to Back Buffer)                                                                                                                                                                                                                
    ┌───────────┐                                                                                                                                                                                                                                 
    │ Buffer A  │ (Active - Being read by Core 1 @ 144 Hz)                                                                                                                                                                                        
    ├───────────┤                                                                                                                                                                                                                                 
    │ Buffer B  │ (Back - Written by Core 0)                                                                                                                                                                                                      
    └───────────┘                                                                                                                                                                                                                                 
          ▲                                                                                                                                                                                                                                       
          │ (Atomic Pointer Swap on packet ready)                                                                                                                                                                                                 
  [Core 1: 144 Hz Rendering Engine]                                                                                                                                                                                                               
  ```                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                  
  ---                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                  
  ## 3. Watchdog & Timing Determinism                                                                                                                                                                                                             
  - **Core 1 Task Watchdog (TWDT):** Monitored every frame. Any frame execution exceeding 6.5 ms triggers an internal performance warning before hardware watchdog intervention.                                                                  
  - **Zero Allocations Rule:** No calls to `malloc()`, `calloc()`, or `free()` are permitted inside `led_render_task` or network packet handlers. All buffers are statically allocated in DRAM at startup.
